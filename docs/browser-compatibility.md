# 浏览器兼容与验证范围

当前清单版本为 0.1.9。源码基于 Manifest V3，不需要构建工具才能运行。

| 平台 | 当前记录 | 发布边界 |
| --- | --- | --- |
| Chrome 155 | 修复后的自动化回归、原生扩展安装与缓存测试通过；限定真实会话检查由用户确认 | 最终商店包仍需按 testing.md 验收真实长历史、分支、会话切换和布局 |
| Edge 155 | 导航回归、缓存回归及原生扩展集成通过 | Edge 商店需独立提交与最终包验收 |
| Firefox | 清单最低版本为 157；本轮改动的原生与签名发行补验待完成 | 不据打包成功宣称该版本已完成 Firefox 验收 |

模拟会话测试使用独立临时浏览器配置，不访问真实账号。原生集成测试使用真实扩展存储；模拟测试不能替代真实 ChatGPT 页面与签名包验收。

测试命令与运行时配置见项目 README。Firefox DOM 回归需兼容的 Playwright Firefox；原生集成另需 Selenium 与 geckodriver。各工具属于开发依赖，不是扩展的运行依赖。
