# 首次发布验收

## 前置条件

运行 `python3 scripts/package.py`，把 Chromium ZIP 解压到独立目录，再从 Chrome 或 Edge 的扩展管理页加载该目录。Firefox 使用对应包临时加载；签名版收到后需重新安装验收。

## 检查项

- [ ] 扩展管理页显示最终产品名和版本；工具栏图标清楚，配置页可打开。
- [ ] 真实 ChatGPT 长会话首次加载有明确提示，可停止；结束后恢复阅读位置。
- [ ] 再次悬停不触发扫描；刷新后缓存复用正常，不混入其他会话。
- [ ] 问题和回答章节跳转准确；顶部、底部按钮覆盖整个会话历史。
- [ ] 四种布局、亮暗主题、两侧固定与按钮正常；当前桌面窗口正文和输入框不被目录遮挡。
- [ ] 停用扩展后页面留白恢复；窄窗口行为符合 README。
- [ ] 公开隐私链接无需登录；商店截图无个人会话；安装包无测试、Git 或本地记录。
- [ ] 签名后的 Firefox XPI 可安装，重启后仍可用。

Firefox 签名检查仅适用于 Firefox 发行，不阻断 Chrome 单平台首发。

这些检查需要真实网站登录态、人的视觉判断或平台签名，模拟会话测试不能替代。发现问题先记录浏览器版本、布局、窗口尺寸和步骤；不要把个人会话截图作为公开 issue 附件。
